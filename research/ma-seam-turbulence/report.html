Per-country forecast curves: the early "turbulence", explained & fixed

Desktop DAU, June 2026 forecast cycle · diagnosis in research/ma-seam-turbulence/ · full hypothesis log in LOG.md

Executive summary. When we first plotted the per-country forecast curves (28-day moving averages), the forecast line oscillated for about a month right after the forecast-start date and then went smooth — strongest for small, "spiky" countries like Argentina, and absent for large steady ones like the US. This was a charting artifact, not a problem with the forecast. The 28-day average, for its first ~4 weeks, was silently mixing the last few weeks of actual data with the new forecast; because a country's weekend-vs-weekday swing in the forecast is smaller than in its raw history, that mix didn't cancel cleanly and produced a visible wobble. The underlying daily forecast and every headline number (e.g. the Dec-15 figure) were always correct and are unchanged. We fixed the chart so the line is smooth from day one.

2. What it is NOT (ruled-out explanations)

Not "overfit weekly seasonality in the model." A 28-day average is exactly four weeks, so it mathematically cancels any 7-day cycle; a weekly pattern also has constant size into the future and so cannot produce a fading wobble. We confirmed the forecast-only average (no actuals in the window) is smooth for every country.
Not the logistic growth cap, the hierarchical reconciliation step, or Monte-Carlo sampling noise. Each of those would disturb the daily forecast itself, which would show up in the forecast-only average — it doesn't.
Not a data glitch on the last day. Argentina's last training day is a Monday and its weekends run ~50% of weekdays, so the apparent "86% jump" at the seam is just its normal day-of-week swing, not bad data.

3. Root cause

A 28-day average cancels a weekly cycle only when the cycle is steady across the whole window. For the first 27 forecast days the window straddles the actuals→forecast seam, and the forecast's weekly swing is damped relative to the recent actuals' swing (the model smooths the weekend dip). That amplitude mismatch leaves a weekly residual that slides as the window advances — the wobble. The bigger the mismatch, the bigger the wobble; countries whose forecast matches their actuals (US, CA, JP) stay smooth. (Amplitude is the dominant channel; CN is the one country with matched amplitude that still wobbles — its seam carries a level/phase jump instead. Either way the chart fix below handles it.)

4. Validation — the April backtest (out-of-sample)

We can check the smoothing against reality: April 2026's forecast transition is now in the past, so its realized 28-day average is known (it lives in the current parquet's training rows). We re-ran both methods on the April forecast and scored each transition against what actually happened, using a bias-removed (shape) error so a forecast's level miss doesn't get charged to the charting method.

On the global (all-countries) curve — the headline deliverable — the new transition is a clear win: desktop shape error drops 70% (302,518 → 90,660 DAU; raw error −80%), mobile 18%. The straight bridge ignored the forecast's real trend curvature across the seam; the variance-matched transition rides it.

Per country it is a win for most markets (AR shape error −69%, plus US, CA, DE, ID, IT, MX, PL, ROW), and AR shows the curvature capture vividly:

Scope & known limitation (by design). This is a bandaid for the global curve, not a per-country fix. A handful of small high-volatility countries (e.g. desktop IN, CN, FR) do worse on demeaned shape — there the April forecast's own trend curvature diverged from what happened, so the new method faithfully tracks a curve that was wrong in hindsight while a straight line happened to sit closer. These cancel out in the global aggregate (what stakeholders see). Separately, the reconstruction leaves a small (<~1%) kink at the day-27 hand-off for the highest-swing countries (AR, BR); the global hand-off is smooth (~0.09%). Both are accepted v1 limitations, documented, not chased.

5. The fix

In the chart export (data-official/2026-06/export_canonical_curves.py, function display_ma) the forecast 28-day average from "+27 days" onward is built from forecast data only (unchanged). For the first 27 days — where the trailing window still straddles the seam — we no longer draw a straight line. Instead we rebuild the forecast's first 27 daily values to carry the recent actuals' weekly amplitude (its weekday/weekend swing), keeping the forecast's own trend. Both sides of the seam then share the same weekly shape, the 28-day window cancels it cleanly, and the transition rides the forecast's true trend — curvature and all — instead of a featureless straight line. Result: the line starts exactly at the forecast date, no gap, no wobble, and it tracks where the forecast is actually heading. Every date from "+27 days" onward (including Dec-15) is byte-for-byte identical to before, so no headline number moved. The same transition is applied to the prior-cycle (April) comparison line.

6. Why it won't recur

A regression suite — tests/test_export_canonical_curves.py — builds synthetic countries with a deliberate weekend-amplitude drop at the seam and asserts: the old method would wobble (anti-tautology); the new transition is far smoother; the day-27 hand-off to the forecast-only average has no kink; every date past "+27 days" stays byte-identical to the plain average (Dec-15 preservation); and — on a curved-trend fixture — the variance-matched transition tracks the realized average better than a straight line, proving the refinement is real curvature capture, not cosmetic. The out-of-sample April backtest (research/ma-seam-turbulence/backtest_seam.py) gates the change on the global curve. If anyone reintroduces the seam blend, reverts to the straight bridge, or perturbs the far-horizon values, the tests fail.
