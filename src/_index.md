# src/ — package source root

Contains the `mozaic_daily` Python package. Nothing else belongs here.

## Contents

| Directory | What's in it |
|---|---|
| `mozaic_daily/` | Main forecasting package — data fetching, forecasting, formatting, validation |

## Where new code goes

All application code lives under `mozaic_daily/`. New modules within the package go there, not at the `src/` level.
